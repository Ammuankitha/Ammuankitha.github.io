# Ankitha Betala — Portfolio Website

A responsive static portfolio website built with HTML, CSS, and vanilla JavaScript. It is ready to publish using GitHub Pages.

## Preview locally
Open `index.html` in a browser. For a local server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example `ankitha-portfolio`).
2. Upload all files and folders in this directory, preserving the folder structure.
3. Open **Settings → Pages** in the repository.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will provide the published site URL after deployment.
